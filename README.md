# Ilhmnra · UI/UX design portfolio

Two interactive, self-initiated concepts for web and mobile app design.

- **Counterform** helps a designer inspect reclaimed terracotta and preview a lot reservation.
- **Night Ferry** helps a rider compare late-night transfer windows and save a fictional trip.

Serve with `python -m http.server 8000 --directory site` from this repository, then open `http://localhost:8000`. The website uses HTML, CSS, local fonts, and browser JavaScript. Reservation, timetable, and trip saving are prototype-only. Images are original generated specimen illustrations. The fonts ship under the license files in the asset directory.

The GitHub Pages workflow publishes the contents of the static site directory. The portfolio and its screenshots use original content.
